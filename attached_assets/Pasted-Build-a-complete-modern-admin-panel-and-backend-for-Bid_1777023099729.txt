Build a complete modern admin panel and backend for Biddi Rides.

Project:
Biddi Rides is a simplified ride-hailing / ride-bidding app.
There is ONE mobile app for both riders and drivers.
The app supports only the bidding ride request concept for now.
Do not build rental, hotel, delivery, intercity, pool, corporate, MLM, gift card, or multi-service marketplace features.

Admin goal:
Create a clean professional admin dashboard inspired by the old screenshots, but simplify it for the new Biddi MVP.

IMPORTANT BUSINESS RULES:
- This new admin is for bidding rides only.
- Rider requests a ride.
- Drivers submit bids.
- Rider accepts one bid.
- Trip starts.
- Trip ends.
- Payment is cash for MVP.
- Admin commission is calculated from accepted bid/final amount.
- Driver can be approved inside admin.
- Same mobile user can be rider and driver.
- App mode switch is only available after driver approval.
