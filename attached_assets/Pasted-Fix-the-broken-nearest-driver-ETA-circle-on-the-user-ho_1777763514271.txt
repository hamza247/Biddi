Closest driver logic:
1. Get user current latitude/longitude
2. Get available/online drivers
3. Filter drivers with valid coordinates
4. Calculate distance from user to every driver
5. Select the nearest driver
6. Calculate ETA

Step 4 — ETA Calculation

Use the best available method already in the app.

Priority:
1. If the app already uses routing/directions API, use route duration.
2. If routing API is unavailable, use fallback calculation:
   - distanceKm = haversine(userLocation, driverLocation)
   - average city speed = 25 km/h
   - etaMinutes = ceil((distanceKm / 25) * 60)
   - minimum ETA = 1 minute

Make the fallback reliable.

Add helper functions if missing:

- isValidCoordinate(lat, lng)
- haversineDistanceKm(pointA, pointB)
- calculateFallbackEtaMinutes(distanceKm)
- getClosestDriver(userLocation, drivers)
- formatEta(minutes)
