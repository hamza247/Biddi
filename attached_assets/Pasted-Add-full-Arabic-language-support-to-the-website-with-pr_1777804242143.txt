Add full Arabic language support to the website with proper RTL (Right-to-Left) layout and localization.

Goals:
- Provide a complete Arabic version of all website pages
- Ensure professional RTL UI/UX
- Maintain clean, scalable, and maintainable code

Requirements:

1. Internationalization (i18n)
- Implement a proper i18n system (e.g., i18next or similar)
- Support at least:
  - English (en)
  - Arabic (ar)
- Store translations in structured JSON files (e.g., /locales/en.json, /locales/ar.json)
- Do not hardcode text in components

2. Language Switcher
- Add a visible language switcher in the header (EN / AR)
- Save user language preference (localStorage or cookie)
- Automatically detect browser language on first visit

3. RTL Support
- When Arabic is selected:
  - Set <html dir="rtl" lang="ar">
  - Flip layout direction (flex, grid, margins, paddings)
  - Mirror UI elements (icons, arrows, navigation)
- Ensure all components work correctly in RTL

4. Typography
- Use a high-quality Arabic font (e.g., Cairo, Tajawal, or similar)
- Ensure proper font loading and fallback
- Adjust font sizes and line heights for Arabic readability

5. UI Adjustments
- Align text to the right in Arabic
- Reverse navigation layout
- Adjust spacing, icons, and buttons for RTL
- Ensure forms, inputs, and placeholders support Arabic correctly

6. Page Coverage
Add Arabic support to all pages, including:
- Home
- Authentication (Login / Register)
- Dashboard
- Search pages
- Admin panel (if applicable)
- Footer and header
- Error pages

7. Content Translation
- Translate all UI text into Modern Standard Arabic
- Keep tone simple, clear, and professional
- Avoid literal translations; use natural Arabic phrasing

8. SEO Support
- Add proper <html lang="ar"> when Arabic is active
- Support localized URLs if possible:
  - /en/...
  - /ar/...
- Ensure meta tags are translated

9. Performance
- Lazy-load translation files
- Avoid re-rendering entire app unnecessarily
- Keep bundle size optimized

10. Testing
- Verify all pages in RTL mode
- Ensure no layout breaking
- Test switching languages dynamically
- Test mobile responsiveness in Arabic

11. Clean Architecture
- Centralize translation logic
- Make it easy to add more languages later
- Keep code modular and reusable

Expected Output:
- Fully working bilingual website (English + Arabic)
- Smooth language switching
- Professional RTL layout
- Clean, scalable i18n implementation
