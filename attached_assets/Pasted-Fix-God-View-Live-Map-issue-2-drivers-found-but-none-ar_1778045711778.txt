Fix God View / Live Map issue: “2 drivers found, but none are sharing a live location”.

Problem:
Admin Live Map finds drivers in the system, but none appear on the map because the app thinks they are not sharing live location.

Goal:
Make available/online drivers show correctly on the admin map with live location markers.

Important:
- Do NOT use fake driver coordinates.
- Do NOT hardcode markers.
- Do NOT only hide the message.
- Fix the real issue in driver location saving, API response, data mapping, and map rendering.

Fix the correct source of truth.

- Location watcher starts when driver is online
- Location updates are sent to backend
- Driver online status is saved
- Location is sent with correct field names

Only send location when:

Step 4 — Fix backend location update endpoint

Find or create endpoint:

POST /api/driver/location/update

Expected payload:

{
  "lat": 33.5731,
  "lng": -7.5898
}

Backend should:
- Validate lat/lng
- Convert to numbers
- Save driver current location
- Save last_location_at timestamp
- Update driver online/live status if needed
- Emit socket event to admin map if socket exists

Validation:
- lat must be between -90 and 90
- lng must be between -180 and 180
- reject null/undefined/empty
- reject 0,0 unless intentionally valid

Fix if:

- API does not join driver location table
- API filters out online drivers

Add last_location_at.

- Still show in list with “stale location”.
- Do not show as active live marker unless valid and recent.
