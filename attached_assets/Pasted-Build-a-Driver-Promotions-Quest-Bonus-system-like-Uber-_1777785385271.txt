Build a Driver Promotions / Quest Bonus system like Uber.

Goal:
Allow admins to create promotions where drivers earn a bonus after completing a required number of rides within a specific day/week/time window.

Example:
“Complete 1 trip between Sat 6:00 PM and Sun 2:00 AM to earn $2.”

Important:
- Do NOT rebuild the app.
- Use existing driver, trip, wallet, admin, and notification systems.
- Keep code clean, simple, and optimized.
- Do NOT over-engineer.
- Rewards must be credited only once.
- Cancelled rides do NOT count.

Admin Panel Feature:
Create page: Driver Promotions

Admin can:
- Create promotion
- Edit promotion
- Delete promotion
- Activate/deactivate promotion
- View driver progress
- View completed rewards

Promotion fields:
- Promotion title
- Description
- Bonus amount
- Currency
- Required completed trips
- Start date/time
- End date/time
- Repeat type: none / daily / weekly
- Eligible area/zone optional
- Eligible vehicle type optional
- Eligible drivers: all / selected drivers
- Status active/inactive

Backend Logic:
When a trip is completed:

1. Check active promotions.
2. Verify trip completed within promotion time window.
3. Verify driver is eligible.
4. Verify vehicle type if promotion has vehicle restriction.
5. Verify zone/area if promotion has location restriction.
6. Check trip was not already counted for this promotion.
7. Add trip to promotion progress.
8. If completed_trips_count reaches required_trips:
   - Mark promotion progress completed.
   - Credit driver wallet.
   - Create wallet transaction.
   - Send notification to driver.
9. Prevent duplicate bonus credit.

Helper functions:

- isTripEligibleForPromotion(trip, promotion)
- updatePromotionProgress(driverId, tripId)
- creditPromotionBonus(driverId, promotionId)
- getDriverPromotionProgress(driverId)

Rules:
- Only completed trips count.
- Cancelled trips do not count.
- Trips outside start/end time do not count.
- Same trip cannot count twice.
- Bonus credited once per promotion per driver unless repeat cycle allows new progress.
- If repeat weekly/daily, create a new progress cycle per period.
