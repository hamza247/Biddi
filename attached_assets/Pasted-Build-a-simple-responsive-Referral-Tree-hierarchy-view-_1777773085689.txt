Build a simple, responsive Referral Tree (hierarchy view) for users and drivers.

Goal:
Allow a user or driver to see:
- Who they referred
- Which level each referred user belongs to (Level 1, 2, 3)
- A clean visual tree (like parent → children)

Important:
- Keep it VERY simple (no complex graph libraries unless needed)
- Must be fast and responsive (mobile + desktop)
- Max depth = 3 levels
- Do NOT over-engineer

--------------------------------------------------
DATA STRUCTURE
--------------------------------------------------

Use existing users table:

users:
- id
- name
- referral_code
- referred_by (user_id)

Build referral tree like:

User A
 ├── User B (Level 1)
 │    ├── User C (Level 2)
 │    │    └── User D (Level 3)

--------------------------------------------------
BACKEND
--------------------------------------------------

Create endpoint:

GET /api/referrals/tree

Input:
- userId

Output:

{
  "user": {
    "id": 1,
    "name": "ABC Member"
  },
  "children": [
    {
      "id": 2,
      "name": "Member 1",
      "level": 1,
      "children": [
        {
          "id": 3,
          "name": "Member 2",
          "level": 2,
          "children": [
            {
              "id": 4,
              "name": "Member 3",
              "level": 3,
              "children": []
            }
          ]
        }
      ]
    }
  ]
}

Rules:
- Only go up to 3 levels
- Avoid recursive heavy queries
- Use efficient queries (max 3 loops or batched query)
- Return only necessary fields

Create a simple tree layout:

Each node (card) shows:
- User name

Design:
- Horizontal tree (like your screenshot)

Example layout:

[ABC Member]
     |
[Member 1 - L1]
     |
[Member 2 - L2]

[Member 3 - L3]

OR grid style:
Parent → children side by side
