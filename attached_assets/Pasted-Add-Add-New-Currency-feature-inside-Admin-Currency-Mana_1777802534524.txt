Add “Add New Currency” feature inside Admin → Currency Management.

Goal:
Allow admin to add, edit, activate/deactivate, and manage more currencies from the admin panel.

Important:
- Do NOT rebuild the app.
- Reuse existing Currency Management page, database, API, and settings structure.
- Do NOT hardcode currencies only in frontend.
- Currency data must persist in database.
- Keep code clean, simple, and optimized.

Features:

1. Currency List
Admin should see:
- Currency code
- Currency name
- Symbol
- Exchange rate from USD
- Status active/inactive
- Default currency badge
- Last updated date
- Actions: Edit / Delete / Activate / Deactivate / Set as Default

2. Add Currency Form
Fields:
- Currency Code: example USD, MAD, EUR, CAD
- Currency Name: example US Dollar, Moroccan Dirham
- Currency Symbol: example $, MAD, €, C$
- Exchange Rate From USD
- Decimal Places: default 2
- Symbol Position: before / after
- Thousands Separator: comma / dot / space
- Decimal Separator: dot / comma
- Status: active/inactive

Validation:
- Currency code required
- Currency code must be 3 uppercase letters
- Currency code must be unique
- Currency name required
- Symbol required
- Exchange rate must be positive number
- Decimal places must be 0–4

3. Edit Currency
Admin can update:
- name
- symbol
- exchange rate
- formatting options
- status

Do not allow changing currency code if it is already used in transactions, fares, wallets, or payments.

4. Delete Currency
Allow delete only if currency is not used anywhere.

If used, block delete and show:
“This currency is already used in fares, payments, wallets, or transactions. You can deactivate it instead.”

5. Default Currency
Admin can set one active currency as default.

Rules:
- Only one default currency allowed.
- Default currency cannot be inactive.
- Default currency cannot be deleted.
- App should use default currency for new fares/settings unless another currency is selected.

6. Exchange Rate Integration
Use existing daily exchange-rate updater if available.

If not available, connect to:
https://open.er-api.com/v6/latest/USD

Admin actions:
- Manual “Update Rates Now” button
- Auto-update daily via cron
- Update only active currencies
- Keep previous rates if API fails

7. Backend/API
Create or update endpoints:

GET /admin/currencies
GET /admin/currencies/:id
POST /admin/currencies
PUT /admin/currencies/:id
DELETE /admin/currencies/:id
PATCH /admin/currencies/:id/status
PATCH /admin/currencies/:id/set-default
POST /admin/currencies/update-rates

8. Database
Inspect existing currency table first.

Use existing table if available.

currencies:
- id

- name
- symbol

- decimal_places
- symbol_position
- thousands_separator
- decimal_separator
- is_active

- last_rate_updated_at
- created_at
- updated_at

Indexes:
- unique code
- is_active
- is_default

9. Currency Formatting Helper
Create reusable helper:

formatCurrency(amount, currencyCode)

It should apply:
- symbol
- symbol position
- decimal places
- separators

Examples:
- USD: $10.00
- MAD: 10.00 MAD
- EUR: €10.00

- General Settings currency dropdown
- Zone/geofence currency dropdown
- Fare configuration currency dropdown
- Wallet display

- Reports
