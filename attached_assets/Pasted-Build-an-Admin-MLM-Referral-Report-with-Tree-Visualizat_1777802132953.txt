Build an Admin MLM Referral Report with Tree Visualization.

Goal:
Allow admin to view referral relationships, levels, earnings, and MLM structure in a clean visual tree.

Important:
- Do NOT rebuild the app.
- Use existing referral/users/wallet tables if available.
- Keep it simple, fast, and responsive.
- Max referral depth = 3 levels.
- Do NOT use heavy graph libraries unless absolutely needed.

Admin Page:
Create page: MLM Referral Report

Features:
1. Search user/driver by:
- Name
- Phone
- Email
- Referral code

2. Show referral tree:
- Root user/driver
- Level 1 referrals
- Level 2 referrals
- Level 3 referrals

Each node should show:
- Name
- User type: rider / driver
- Referral code
- Level
- Total referrals
- Total referral earnings
- Joined date
- Status

Tree UI:
- Clean card-based tree
- Parent → children connection lines
- Expand/collapse nodes
- Different color badges:
  - Level 1 = blue
  - Level 2 = green
  - Level 3 = orange
- Mobile responsive
- Horizontal scroll on desktop if needed
- Vertical stacked view on mobile

Report Summary Cards:
Show:
- Total Level 1 referrals
- Total Level 2 referrals
- Total Level 3 referrals
- Total referral earnings
- Total rewards paid
- Pending rewards

Data Logic:
- Build referral tree from referred_by / referral_code relationship.
- Limit depth to 3 levels.
- Include earnings from referral_earnings table if available.
- If no earnings table exists, show 0.
- Avoid recursive heavy DB queries.
- Use max 3 level queries or optimized batched query.
- Prevent circular referral loops.
