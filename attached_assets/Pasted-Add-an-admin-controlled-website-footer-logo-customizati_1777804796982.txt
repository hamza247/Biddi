Add an admin-controlled website footer logo customization feature.

Goal:
Allow the admin to upload and manage the website footer logo instead of using the hardcoded logo/text.

Requirements:

1. Admin Panel
- Add a new setting in Admin Panel: Website Branding
- Add section: Footer Logo
- Admin can upload a custom logo image
- Supported formats: PNG, JPG, JPEG, SVG, WEBP
- Max file size: 2MB
- Show preview before saving
- Show current active footer logo
- Add buttons:
  - Upload Logo
  - Save Changes
  - Remove Logo
  - Restore Default Logo

2. Footer UI
- Replace the hardcoded footer logo with the uploaded logo
- If no custom logo exists, show the default logo
- Keep the footer layout clean and responsive
- Logo should fit properly without breaking design
- Recommended max height: 48px
- Preserve aspect ratio
- Support dark and light backgrounds if possible

3. Backend
- Create API endpoints:
  - GET /api/admin/branding
  - POST /api/admin/branding/footer-logo
  - DELETE /api/admin/branding/footer-logo
- Store uploaded logo securely
- Save logo URL/path in database or settings table
- Validate file type and size
- Protect endpoints with admin authentication

4. Storage
- Store uploaded logos in a safe public uploads directory
- Example: /uploads/branding/footer-logo
- Generate unique filenames
- Delete old logo when a new one is uploaded
- Do not expose server filesystem paths to frontend

5. Database
- Add branding/settings table if missing
- Store:
  - footerLogoUrl
  - updatedAt
  - updatedBy

6. Frontend
- Fetch branding settings on website load
- Use footerLogoUrl in footer component
- Add fallback default logo
- Handle loading and error states gracefully

7. Security
- Only authenticated admins can upload/remove logo
- Validate MIME type
- Prevent executable file uploads
- Sanitize filenames
- Limit upload size
- Return safe public URL only

8. Testing
- Test upload PNG/JPG/SVG/WEBP
- Test remove logo
- Test fallback default logo
- Test mobile footer layout
- Test admin permissions

Expected result:
Admin can upload a customized footer logo from the admin panel, and the website footer automatically displays the new logo with proper sizing and fallback behavior.
