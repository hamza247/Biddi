Add automatic daily currency exchange updates using this API:

https://open.er-api.com/v6/latest/USD

Goal:
Keep all app currencies updated daily based on USD exchange rates and use them in fare calculations, wallet, and admin display.

Important:
- Do NOT hardcode exchange rates
- Do NOT call API on every request (use caching)
- Must be efficient and reliable
- Must not break existing pricing logic
- Handle API failures safely

--------------------------------------------------
PART 1 — DATABASE DESIGN
--------------------------------------------------

Use or create table:

currencies:
- code (USD, MAD, EUR)
- name
- symbol
- rate_from_usd
- last_updated_at
- is_active

Indexes:
- code

--------------------------------------------------
PART 2 — FETCH EXCHANGE RATES
--------------------------------------------------

API:
GET https://open.er-api.com/v6/latest/USD

Response:
{
  "base_code": "USD",
  "rates": {
    "MAD": 10.1,
    "EUR": 0.92,
    ...
  }
}

--------------------------------------------------
PART 3 — BACKEND SERVICE
--------------------------------------------------

Create service:

updateCurrencyRates()

Logic:
1. Call API
2. Extract rates
3. Loop currencies in DB
4. Update rate_from_usd
5. Update last_updated_at

Only update currencies that exist in DB.

--------------------------------------------------
PART 4 — SCHEDULER (CRON JOB)
--------------------------------------------------

Run update automatically:

- Every 24 hours (recommended)
OR
- Every 12 hours for more accuracy

Example:
cron: 0 2 * * *

Do NOT run per request.

--------------------------------------------------
PART 5 — CACHING
--------------------------------------------------

- Store rates in DB
- Optional: cache in memory (Redis)
- TTL: 24h

Fallback:
If API fails:
- Keep last stored rates
- Log error
- Do NOT crash system

--------------------------------------------------
PART 6 — CURRENCY CONVERSION
--------------------------------------------------

Create helper:

convertFromUSD(amount, targetCurrency)

Example:
amount * rate_from_usd

Also create:

convertBetweenCurrencies(amount, from, to)

Logic:
1. Convert to USD
2. Convert USD to target

--------------------------------------------------
PART 7 — INTEGRATION
--------------------------------------------------

Apply currency rates to:

- Fare calculation
- Wallet balance
- Payment display
- Admin reports

Ensure:
- All prices use correct currency
- No mismatch between frontend/backend

--------------------------------------------------
PART 8 — ADMIN PANEL
--------------------------------------------------

Add page:

Currency Management

Features:
- View all currencies
- Show:
  - Code
  - Symbol
  - Exchange rate
  - Last updated
- Manual “Update Now” button
- Enable/disable currency

--------------------------------------------------
PART 9 — ERROR HANDLING
--------------------------------------------------

Handle:

- API down
- Invalid response
- Missing rates
- Network timeout

Log errors properly.

--------------------------------------------------
PART 10 — TESTING
--------------------------------------------------

Test:

1. API fetch works
2. Rates stored correctly
3. Cron job runs
4. Conversion correct
5. Fallback works when API fails
6. Admin update works
7. No performance issue

--------------------------------------------------
PART 11 — CODE QUALITY
--------------------------------------------------

- Modular functions:
  - fetchRates()
  - updateCurrencyRates()
  - convertCurrency()

- No duplicate logic
- No hardcoded rates
- Clean error handling

--------------------------------------------------
FINAL OUTPUT REQUIRED
--------------------------------------------------

Provide:

- Backend service
- Cron setup
- DB changes
- Conversion helpers
- Admin UI changes
- Test results

--------------------------------------------------
IMPORTANT RULE
--------------------------------------------------

Rates must be:
- accurate
- cached
- updated daily
- never fetched on every user request
