Build a real-time Driver Heatmap with Surge Pricing for the driver app.

Goal:
Create a map overlay that shows demand zones using colors (heatmap) and dynamic surge pricing per area, similar to Uber.

Important:
- Do NOT fake data
- Do NOT hardcode zones
- Must be dynamic based on real demand/supply
- Keep performance optimized (no heavy calculations on frontend)
- Use backend-driven aggregation
- Smooth UI (no lag)

--------------------------------------------------
FEATURE OVERVIEW
--------------------------------------------------

The driver map should display:

1. Heatmap overlay showing demand intensity
2. Surge price labels (e.g. +$1.75 or 1.5x)
3. Color-based zones:
   - Low demand → light yellow
   - Medium demand → orange
   - High demand → red
   - Very high demand → dark red / purple

4. Real-time updates every few seconds

--------------------------------------------------
DATA LOGIC (CORE)
--------------------------------------------------

Heatmap should NOT be random.

It must be calculated using:

Demand = number of ride requests in area  
Supply = number of available drivers in area  

Surge formula example:

surgeMultiplier = demand / (supply + 1)

Then normalize:

if surge < 1 → no color  
1–1.2 → light  
1.2–1.5 → medium  
1.5–2 → high  
2+ → very high  

Also support flat bonus:
Example:
+1.75 USD instead of multiplier

--------------------------------------------------
BACKEND DESIGN
--------------------------------------------------

Create endpoint:

GET /api/driver/heatmap

Response:

{
  "zones": [
    {
      "lat": 41.88,
      "lng": -87.62,
      "intensity": 0.8,
      "surgeMultiplier": 1.6,
      "bonus": 1.75
    }
  ]
}

How to calculate zones:

- Divide city into grid (ex: 500m x 500m)
- Aggregate:
  - count active ride requests
  - count available drivers
- Compute surge
- Return only zones with meaningful demand

Use caching:
- Refresh every 10–30 seconds
- Avoid heavy DB queries each request

--------------------------------------------------

Use:

OR

On update:
- Diff old vs new zones
- Update only changed zones
- Do NOT rerender full map
