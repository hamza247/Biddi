Switch the map base layer to the standard Google Maps “Roadmap” style across the app.

Goal:
Use the clean light-gray Google Maps default style (like the screenshot) as the base layer for all maps where applicable.

Important:
- Do NOT break existing map features (markers, heatmap, routes, etc.)
- Do NOT remove overlays (heatmap, surge, drivers, zones)
- Only replace the base map layer/style
- Keep performance optimized

--------------------------------------------------
PART 1 — IDENTIFY CURRENT MAP USAGE
--------------------------------------------------

Search and identify:
- Where maps are used (driver app, user app, admin panel)
- Which libraries are used:
  - Google Maps SDK
  - React Native Maps
  - Leaflet
  - Mapbox

List:
- All map components
- All map initialization code
- All tile layers or mapTypeId usage

--------------------------------------------------
PART 2 — APPLY GOOGLE ROADMAP STYLE
--------------------------------------------------

If using Google Maps (Web or React Native Maps):

Set:

mapTypeId: "roadmap"

OR in React Native Maps:

<MapView
  mapType="standard"
/>

Ensure:
- No custom dark styles override it
- No satellite/hybrid mode is enabled
- Remove any custom style JSON if present

--------------------------------------------------
PART 3 — IF USING LEAFLET (ADMIN PANEL)
--------------------------------------------------

Replace existing tile layer with clean OpenStreetMap standard:

L.tileLayer('https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png', {
  attribution: '&copy; OpenStreetMap contributors'
})

Ensure:
- No dark tiles
- No satellite tiles
- No custom styled tiles
- Proper zoom levels
- Proper retina support if needed

Optional (closer to Google look):
Use Carto Light style:

https://{s}.basemaps.cartocdn.com/light_all/{z}/{x}/{y}{r}.png

--------------------------------------------------

- Surge pricing labels
- Routes/navigation
- Polylines

Search and remove:
