Goal:
Implement a 3-level referral system where users earn rewards when their referred users complete rides.

--------------------------------------------------
CORE BUSINESS LOGIC
--------------------------------------------------

Referral works like this:

Example:
User A refers User B  
User B refers User C  
User C refers User D  

Levels:
- Level 1 → direct referral
- Level 2 → referral of referral
- Level 3 → third-level referral

Earnings rule:
- When a ride is COMPLETED:
  distribute rewards up to 3 levels

Example:
Ride = 100 MAD  
Level 1 = 4% → 4 MAD  
Level 2 = 2% → 2 MAD  
Level 3 = 1% → 1 MAD  

Important:
- Rewards ONLY after trip completion
- No reward on cancelled rides
- No duplicate reward
- Prevent self-referral abuse

--------------------------------------------------
REFERRAL FLOW
--------------------------------------------------

1. User signup:
- Generate unique referral_code
- Allow entering referral code
- Save referred_by

2. Trip completed:
- Trigger referral calculation
- Traverse up to 3 levels
- Calculate reward
- Insert referral_earnings
- Credit wallet

3. Reward distribution:
- Stop if no parent exists
- Stop at max 3 levels
- Skip inactive levels

--------------------------------------------------
OPTIMIZED ALGORITHM (IMPORTANT)
--------------------------------------------------

Do NOT use recursive DB calls inside loops.

Instead:
- Fetch referral chain in ONE query if possible
- Or loop max 3 times (acceptable)
- Avoid deep recursion

Pseudo logic:

currentUser = trip.user_id

for level in 1 → 3:
  parent = get referred_by(currentUser)
  if no parent → break

  percentage = get level percentage
  amount = trip_amount * percentage

  create referral_earning
  credit wallet

  currentUser = parent
